How it works

Five steps, one command, no manual copy. Each step only reads the one before it.

Snapshot

The library is read into one neutral file: tokens, styles, components, and what every layer binds.

Tokens

tokens.json and tokens.css, light and dark, desktop and mobile, with their code names.

Checks

Rules that block, rules that warn, and questions that only the owner can answer.

Contract

AI-CONTRACT.md: what an AI tool may use, what it must never use, what to ignore in Figma.

Gate

Exit code 1 while a blocking check fails. A pipeline cannot publish past it.

Decisions live in one file

governance/governance.json holds what people decided: what is deprecated and why, the variant budget, which colour pairs must pass contrast, what an AI tool must never do. People change it through a reviewed change. The checks and the contract are generated from it, so a decision is written once and enforced everywhere.

Run it

python3 pipeline/01_snapshot_from_fig.py <decoded file> build/ds-snapshot.json
python3 pipeline/02_build.py build/ds-snapshot.json governance build

Plain Python, no dependencies. The same checks run on a snapshot taken through the Figma Plugin API (pipeline/01b_snapshot_plugin_api.js), so nobody needs our reader to repeat this.

Limits and what we recommend

What this does not do

  • It cannot see. Clipped shadows, cut-off text and weak composition pass every structural check. Those audit points stay with a person, on purpose.
  • It does not decide taste. How many button states, whether labels are uppercase, which neutrals stay: it measures and asks. The owner answers once, in the governance file.
  • Severity is a proposal. Which rules block and which warn is our suggestion. It is one line each to change.
  • We were wrong once, and the checking caught it. Our first pass reported two typefaces mixed across the file. The layers carry stale font fields; resolved through their text styles it is Barlow on layers and Inter on . A number nobody verified is exactly what the audit warns about.

What we would do next

  • Name one owner and put the name in the governance file. Every open question on this page is waiting for that person.
  • Give the tools the contract, not the Figma link. It answers "what does the AI take from this page?" by taking the pages out of the question.
  • Stop writing the changelog by hand. Two snapshots give the real diff: added, changed, removed, and what each change touches.
  • Clean in this order: remove what is deprecated, fix the contrast pairs, bind the loose values, then cut variants axis by axis.
  • Put the gate in front of publishing. Same command, run on every change, before the library goes out.
