Limits

What this report cannot tell you.
  • It cannot see. Clipped shadows, cut-off text and weak composition pass every structural check. A person still looks at every page.
  • It does not decide taste. How many states, which neutrals stay: it measures and asks. The owner answers once, in the governance file, and the checks enforce it.
  • Severity is a proposal. Which rules block and which warn is one line each to change.
  • Library publishing is not tested. The Figma file lives in drafts, so no other file subscribes to it yet.
