<Section n={6} title="The token rule">
  <List items={[
    <>A new <code>component/*</code> token needs no discussion. It is that component's own business.</>,
    <>A new <code>space/*</code>, <code>radius/*</code> or <code>font-size/*</code> token changes the shared language and needs a reason.</>,
    'Ask: if this value changed, how many components should move? If the answer is one, it belongs in Component.',
    'Status colours come in five roles: error (solid fill), on-error (text on it), error-container, on-error-container and on-surface-error (text on any surface). Never a status hex or a status primitive.',
    'A colour is named by its job, never by where it sits or the mode it is in: surface, on-surface, primary, outline. No colour tokens per component, no inverted or dark copies. Light and Dark, and an inverted band, are modes that switch the same names.',

</Section>
