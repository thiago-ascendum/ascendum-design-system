<Section n={1} title="The path of a change" lead="Seven steps. Each one says who does it.">
  <Steps items={[
    ['Change in Figma', <><Who k="A designer" />Edit a variable, for example the horizontal padding of the Button, in the Component collection.</>],
    ['Snapshot', <><Who k="One click" />The snapshot script reads every variable, alias, component and layer through the Figma Plugin API. It saves a named Figma version first and stores its id, so the snapshot always says where it came from.</>],
    ['Pull request', <><Who k="Automatic" />The snapshot goes to a branch and a pull request. If another collection is still being edited, only the ready one is taken (scoped sync).</>],
    ['Tokens and contracts', <><Who k="Automatic" />One script turns the snapshot into tokens.json, tokens.css, the AI contract and one contract per component. Nobody edits these files by hand.</>],
    ['Gate', <><Who k="Automatic" />GitHub Actions runs the blocking checks: aliases, palette, contrast, code names, breaking changes, colours typed by hand in code, undefined CSS properties. One failure turns the pull request red.</>],
    ['Review', <><Who k="A person" />Someone looks at the preview build and merges. A breaking change must be accepted by name in the same pull request.</>],
    ['Publish and release', <><Who k="Automatic" />After the merge, the site is built and published only if every check passed. A release in GitHub points to the commit and to the Figma version.</>],
  ]} />
</Section>
