# Ascendum Design System

**AI proposes. Checks verify. A person approves.**

This is the coded side of the library. Figma is the source of truth: the tokens here are generated from the Figma file, and the three components below are built from those tokens, binding for binding.

## Four steps

1. **Use the tokens.** Import `build/tokens.css`. Every colour, radius, size and space is a CSS custom property with a light and a dark value.
2. **Bind roles, not colours.** Use `--text`, `--container-fill`, `--feedback-success`. The primitives (`--neutral-750`, `--brand-midnight`) sit behind the roles and you should never need one.
3. **Place components, never rebuild them.** Button, Input and Badge are in `src/components`. If the piece exists, use it and set its properties.
4. **Change it the right way.** Change the design in Figma, take a snapshot, and let the checks run. Nobody edits a token by hand.

## Try it

- Switch **Theme** in the toolbar: the whole canvas changes because the tokens change.
- Open **Components / Button** and use the controls.
- Open **Foundations / Colour**: it is read live from `build/tokens.json`.
